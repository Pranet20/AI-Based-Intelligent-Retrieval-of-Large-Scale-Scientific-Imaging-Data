## 3. Venue-Specific Preparation Actions

### A. If Submitting to IEEE TPAMI
1. **Focus Alignment:** Emphasize the Vision Transformer foundation representation (DINOv2), the contrastive metric learning formulation (SupCon with same-acquisition masking), and the mathematical proof of the metadata negative result.
2. **Formatting:** Export Markdown text into the official `IEEEtran.cls` LaTeX template in `journal` mode.
3. **Supplementary:** Package extended mathematical derivations (SM-1), detailed leakage control proofs (SM-2), and full multi-seed bootstrap confidence intervals (SM-3) into a separate IEEE Supplementary Material document.

### B. If Submitting to IEEE Transactions on Big Data (TBD)
1. **Focus Alignment:** Highlight the scalable data management architecture, FAISS vector indexing latency benchmarks, sub-millisecond retrieval throughput, multi-stage deduplication cascades, and the full-stack FastAPI/React/PostgreSQL platform.
2. **Formatting:** Export Markdown text into the standard IEEE Transactions template.
3. **Supplementary:** Include full database schema specifications (SM-4), redundancy graph clustering algorithms (SM-5), and runtime system benchmarks (SM-7).

### C. If Submitting to Computational Materials Science
1. **Focus Alignment:** Emphasize the metallography domain context (hypoeutectic High-Chromium Cast Iron, primary carbide morphology, austenitization destabilization states `AsCast`, `Q980_0h_WC`, `Q980_9h_AC`), and instrument variance across electron optics.
2. **Formatting:** Convert manuscript into Elsevier single-column or double-column standard submission format.
3. **Supplementary:** Emphasize physical specimen characteristics, multi-instrument operating parameter tables, and metallographic quality screening indicators.
