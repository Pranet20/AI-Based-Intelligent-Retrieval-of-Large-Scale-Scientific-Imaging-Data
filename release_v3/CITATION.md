# Citation & Attribution Guide

If you utilize the *AI-Powered Scientific Image Data Management Platform*, its benchmark methodology, or pre-extracted representations in your academic research, please cite the project using the following format:

### BibTeX Entry
```bibtex
@software{scidata_platform_2026,
  author       = {{Research Team}},
  title        = {{AI-Powered Scientific Image Data Management Platform for Metadata-Aware Retrieval, Acquisition-Robust Representation, Data Integrity Assessment, and Anomaly-Aware Curation}},
  month        = sep,
  year         = 2026,
  version      = {v1.0.0},
  url          = {https://github.com/scidata-platform/scidata-platform}
}
```

### APA Style
Research Team. (2026). *AI-Powered Scientific Image Data Management Platform for Metadata-Aware Retrieval, Acquisition-Robust Representation, Data Integrity Assessment, and Anomaly-Aware Curation* (Version 1.0.0) [Computer software].

---

### External Dataset Citations
When reproducing benchmarks involving third-party datasets, you must also cite the original data authors as detailed in [DATASET_CITATIONS.md](DATASET_CITATIONS.md).
