## Overview

This directory provides the authoritative, frozen evidence package to enable deterministic writing of the IEEE conference paper without requiring further machine learning experiments or statistical recalculations.

### Contents

1. [`canonical_metrics.md`](canonical_metrics.md): Authoritative frozen scientific metrics for every evaluation stage.
2. [`contribution_map.md`](contribution_map.md): Core scientific contributions C1–C4 with strict non-claims.
3. [`claim_evidence_map.md`](claim_evidence_map.md): Direct mapping from research claims to code, artifacts, and test assertions.
4. [`limitation_map.md`](limitation_map.md): Compulsory scientific, methodological, and platform limitations.
5. [`figure_map.md`](figure_map.md): Specification and captions for Figures 1–7.
6. [`table_map.md`](table_map.md): Specification and captions for Tables I–IX.
7. [`reproducibility_statement.md`](reproducibility_statement.md): Deterministic environment, seeds, commands, and code hashes.
8. [`venue_compliance.md`](venue_compliance.md): IEEE ISBI 2027 layout, page-budget, and formatting compliance rules.
9. [`author_metadata.md`](author_metadata.md): Detailed author roster, affiliations, and Human-Review-Required status for primary/first author assignment.
