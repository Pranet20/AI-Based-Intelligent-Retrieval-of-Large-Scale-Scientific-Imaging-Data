## 3. Guiding Scientific Principles
1. **Zero Exaggeration**: No claims of "universal superiority", "state-of-the-art", or "unconditional invariance".
2. **Defensible Phrasing**: Use "measured cross-acquisition similarity gap", "image-derived quality-risk indicators", and "relative embedding-space novelty".
3. **Traceability**: Every numerical metric reported in this manuscript maps directly to a verified artifact in `reports/`.
